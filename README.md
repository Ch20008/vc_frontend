# 游戏标题页面

这是一个基于React的游戏标题页面项目，参考了提供的设计图片。

## 功能特性

- 🎮 游戏标题页面设计
- 📱 响应式布局，支持移动端
- 🎨 现代化的UI设计
- ⚡ 流畅的动画效果
- 🖱️ 交互式点击效果

## 项目结构

```
src/
├── App.js          # 主应用组件
├── App.css         # 主应用样式
├── index.js        # 应用入口
└── index.css       # 全局样式
```

## 安装和运行

1. 安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm start
```

3. 构建生产版本：
```bash
npm run build
```

## 设计特点

- **背景色**: 浅米色 (#f5f5dc)
- **主色调**: 深棕色 (#8B4513)
- **字体**: 现代无衬线字体
- **布局**: 居中布局，响应式设计
- **交互**: 点击屏幕进入游戏，按钮悬停效果

## 组件说明

- **标题区域**: 包含"TITLE"文字和有机图形图标
- **按钮组**: 右上角设置和向上箭头按钮
- **左下角按钮**: 通用功能按钮
- **分割线**: 分隔不同内容区域
- **提示文字**: "点击屏幕进入游戏"
- **版权信息**: 防沉迷公约和版权声明

## 技术栈

- React 18
- CSS3 (动画和响应式设计)
- SVG (图标和图形)
- 现代JavaScript (ES6+)

## 浏览器支持

- Chrome (推荐)
- Firefox
